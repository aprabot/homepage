        Status

        StatusMeaning
        DraftCreated or detected, not committed, or required fields are missing. Editable, and ignored by forecasts
        CommittedLocked and used by every later forecast run. Shown as Planned, Active or Past
        WithdrawnWas committed, and no longer counts in new runs. History is kept
        HistoricalDetected from sales and its details completed. Used for training, not for planning
        ArchivedHidden by the user; kept for history

        Commit actions

        ActionEffect
        Save draftThe scheme stays editable. Every forecast run ignores it
        CommitThe scheme is locked. Every later forecast run treats it as a known price and discount for its scope and dates, and a background re-run starts
        WithdrawA committed scheme stops counting in new runs. Its history is kept, and a copy can become a new version
          Done when
        • A user can create a scheme before or after uploading sales data.
        • A scheme can have several scope lines, each with its own pincodes, SKUs, dates and discount.
        • A draft never changes a forecast; committing a scheme starts a re-run that includes it.
        • A committed scheme cannot be edited; withdrawing it keeps its history and allows a new version.
        • Every distinct scheme_id in a sales upload appears in the tab without any manual step.
        • A created scheme and a detected scheme with the same ID become one row.
        • The user can see which sales rows have a discount but no scheme, and assign them in bulk.
        • A re-upload never erases what the user entered.

        Commit and launch states

        StateMeaning
        DraftEditable; ignored by the forecast
        CommittedLocked; the planned spend counts in every forecast run; the stock check has run
        LaunchedThe campaign exists on Meta or Google through the API; its status follows the platform
        CompletedEnded; actual spend and results recorded
        WithdrawnA committed campaign that was never launched is withdrawn; history is kept
        Save draft, Commit, and Commit and launch are separate buttons, so planning and going live can be done together or apart. Commit runs the inventory view — if baseline demand plus expected uplift exceeds available stock, the page warns; the user can commit anyway or accept a suggested budget cap.
